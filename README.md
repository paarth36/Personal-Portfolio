# Parth Desani — Creative Technologist Portfolio

A responsive, static portfolio built with HTML, CSS, and vanilla JavaScript. No framework installation, build step, watermark, or paid builder is required.

## Run locally

Open `index.html` in a browser, or run a local server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy for free

Upload the folder to GitHub and import the repository into Cloudflare Pages, GitHub Pages, or another static host. The site has no required server-side code.

## Edit details

- Main page: `index.html`
- Styles and responsive layouts: `css/style.css`
- Interactions and animation: `js/main.js`
- Images: `images/`

The site uses Google Fonts when internet access is available and falls back to system fonts if not. Confirm the contact details and project descriptions before publishing.
